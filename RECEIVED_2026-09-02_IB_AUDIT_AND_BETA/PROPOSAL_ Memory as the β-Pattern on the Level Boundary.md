# PROPOSAL: Memory as the β-Pattern on the Level Boundary


**Status:** OPEN — candidate for Stone X
**Origin:** Ilya
**Goal:** give memory a precise group-theoretic definition using the commutator sign β already present in Selina's lift analysis


---


## 1. The Concrete Object


For a level group Γ, define:


```text
M_Γ(g,h) = β(g,h)
```


where:


```text
β(g,h) = commutator sign of the lifts of g and h
```


The memory of the level is the full table:


```text
M_Γ = { β(g,h) | g,h ∈ generating set of Γ }
```


---


2. Why This Is Not Metaphor


β is already computed in the lift-law analysis.


The ε-table already exists.


M_Γ is just the β-table organized by level.


No new physical postulate is introduced.


---


3. What It Should Reproduce


Known fact from the lift law


```text
Split forces all-plus.


All-plus does not force split.
```


Example:


```text
C₄ × C₂ lifts non-split
because commuting generators
lift to anticommuting elements.
```


Therefore:


```text
all-plus cannot detect the difference.
β can.
```


---


4. Proposed Test


Step 1


```text
Compute M_S₃ on the generating set of S₃.
```


Step 2


```text
Compute M_D₄ on the generating set of D₄.
```


Step 3


```text
Compare M_S₃ and M_D₄ with the existing ε-table.
```


Step 4


```text
Exhibit at least one pair (g,h)
where all-plus is identical
but M_Γ differs.
```


---


5. Required Output


```text
1. Table M_S₃.


2. Table M_D₄.


3. Overlay with the ε-table.


4. A concrete pair where β distinguishes
   split from non-split.


5. Statement:
   M_Γ is the memory register of level Γ.
```


---


6. Decision Rule


```text
The proposal is accepted as Stone X if:


- M_Γ is well-defined on each level;


- M_Γ reproduces the ε-table;


- M_Γ detects at least one non-split case
  that all-plus misses.


If M_Γ is only a relabeling of the ε-table
with no new discrimination:
  the proposal is not a new object.
```
