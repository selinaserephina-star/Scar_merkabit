# THE KLEIN COMPUTER — ARCHITECTURE SKETCH


**Status:** speculative model
**Origin:** Ilya
**Subject:** a computer built on the seven points and their character records


---


## 1. Memory Cell


```text
One point of the Klein seven.


State = the character record
        living at that point.


Capacity = one seven-valued record.
```


---


2. Memory Horizon


```text
Three ticks.


After three ticks:
  the cell resets;
  the record is gone.
```


---


3. Write


```text
A compression event.


The surviving character restriction
is written into the next point.
```


---


4. Read


```text
Recover the point stabilizer.


S₄ holds the point.


From S₄, the record is read.
```


---


5. Bus


```text
The shadow side.


Carries search reports upward.


Lifetime also three ticks.
```


---


6. Processor


```text
The descent itself.


Each level is a compression step.


Each step searches for surviving
symmetries.
```


---


7. Clock


```text
The breath.


+ + − − + +


Six transitions per cycle.
```


---


8. Word Size


```text
Seven points.


Each point = one seven-valued
character slot.
```


---


9. Logic


```text
Not binary.


Three outcomes:


  ENTERED
  PARTIAL
  NOT ENTERED
```


---


10. Summary


```text
A ternary-outcome,
seven-point,
character-record machine.


Memory = three ticks.


Bus = shadow return.


Write = compression.


Read = stabilizer recovery.
```
